# Grassroots Golf Co. Website

Static site for [grassrootsgolf.com.au](https://grassrootsgolf.com.au), hosted on GitHub Pages.

## Pages
- `index.html` — Home
- `programs.html` — Programs (Beginner-to-Golfer, Guided Golf, Understand Your Game, Golf Quest, private sessions)
- `about.html` — About, approach and FAQs
- `golf-things.html` — The golf things nobody tells you
- `book.html` — Booking and contact
- `contact.html`, `who-we-help.html`, `our-approach.html` — redirects for older URL patterns
- `styles-v2.css`, `site.js`

Hash links from the previous single-page site (`#about`, `#programs`, `#book`, `#contact`) redirect to the new pages.

## Notes
- The CNAME file (`grassrootsgolf.com.au`) must stay unchanged.
- Logo file: `Grassroots_Golf_LinkedIn_Logo_600x600.png`.
- Colour hierarchy: black `#0B0B0B` banners, green `#063B2C` secondary, gold `#D5AB52` accent, cream `#FAF9F5` background.
- Consented session photographs are stored as the original JPEG uploads in the repository root, with web-sized versions in `photos/`.
